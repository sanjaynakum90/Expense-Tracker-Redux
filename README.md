# 💰 Expense Tracker App

A simple and intuitive **Expense Tracker** built with **React, Vite, and Redux Toolkit**.
This application allows users to add, edit, and delete expenses, categorize them, and manage debit/credit transactions efficiently.

---

## 🚀 Features

* ➕ Add new expenses with title, amount, type, and category
* ✏️ Edit existing expenses
* 🗑️ Delete expenses
* 📂 Categorize expenses (Food, Travel, Shopping, General, etc.)
* 🔄 Manage state globally using **Redux Toolkit**
* ⚡ Fast development setup using **Vite**
* 🎨 Clean and responsive UI

---

## 🛠️ Tech Stack

* **React** – Frontend UI
* **Redux Toolkit** – State management
* **Vite** – Development & build tool
* **JavaScript (ES6+)**
* **CSS** – Styling

## 🧠 Redux State Management

* `expenseSlice.js` handles:

  * Adding expenses
  * Editing expenses
  * Deleting expenses

* `store.js` configures the Redux store and combines reducers.
